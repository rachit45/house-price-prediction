# 🏠 House Price Prediction

A basic Machine Learning web application that predicts house prices based on different house-related features.

The project uses **Python, Pandas, Scikit-learn and Flask** to train a Machine Learning model and provide predictions through a simple web interface.

---

## 📌 Project Overview

House prices depend on several factors such as:

- Location
- Number of rooms
- Number of bedrooms
- Population
- Household size
- Median income
- Ocean proximity

This project uses the California Housing dataset to train a Machine Learning model that predicts the **median house value**.

---

## 🚀 Features

- Load and analyse housing data
- Handle missing values
- Check duplicate values
- Perform basic data analysis
- Encode categorical data
- Split data into training and testing sets
- Train a Machine Learning model
- Predict house prices
- Evaluate the model
- Save the trained model
- Flask web application
- User-friendly HTML/CSS interface
